이 정원의 약속

기록은 이 브라우저에만

학습 기록과 별명은 이 기기의 브라우저 저장소에만 저장돼요. 클라우드 동기화와 백엔드 서버는 없어요. 브라우저 데이터를 지우면 기록도 사라져요. 공용 기기에서는 게스트 이용도 주의해 주세요.

Google 로그인은 선택이에요

로그인은 기기 안에서 Google 사용자별 기록을 구분하고 이름, 프로필 사진, 이메일을 표시하기 위한 기능이에요. ID 토큰은 화면 표시를 위해 브라우저에서 해석할 뿐 서버에서 검증하지 않아요. 발급자·대상·만료·일회 확인값을 브라우저에서 기본 검사하지만 서명 검증이나 서버 인증을 대신하지 않아요. 원본 토큰은 저장하지 않아요. 로그인했다고 자료가 Google에 동기화되지는 않아요.

부모 PIN의 범위

과정을 열거나 닫을 때, 학습자를 추가하거나 기준을 바꿀 때마다 PIN을 확인해요. 이 잠금은 기기 설정용 UI 장치이며 개발자 도구나 저장소 삭제를 막는 강한 보안이 아니에요. 서버 접근 통제도 아니에요. 5회 실패하면 기기에서 30초 동안 확인을 멈춰요.

진단은 출발점을 찾는 도구

과정 전체 진단은 단원마다 기본 문제와 연결 문제를 하나씩 풀어요. 문제를 건너뛴 수와 자신감도 따로 기록해요. 표본이 작아 교육과정 전체 숙달이나 학원 인증을 증명하지 않아요. 한 번 맞았다고 숙달로 표시하지 않아요.

수학지도 탐색과 날짜 복습

전체 수학지도 한 바퀴은 단원마다 연결 수준 한 문제만 풀고 완료 뒤 결과를 보여요. 성긴 선별이며 모든 유형이나 숙달을 증명하지 않아요. 연습에서 틀리면 같은 단원의 다른 문제를 다음에 제안하고 단원당 보충 두 번, 연습당 최대 12문제로 쉬어 가요. 확실한 독립 정답이 다른 날짜에 이어지면 1·3·7·14일 간격으로 복습을 제안해요. 도움받은 정답은 성공 횟수를 늘리지 않고, 틀림·건너뜀은 바로 복습으로 돌아가요. 기록은 모두 이 기기에만 있어요.

문제와 연습 안내

단원 구성은 maths.study를 참고하고 문제는 별도로 만든 원본 연습문제예요. 교사의 검수를 거치지 않았으며 저작권 자료의 복사본이 아니에요. 제한된 문제 은행을 사용하므로 다시 풀 때 이전 문제를 만날 수 있어요. 반복 정답과 힌트 사용 정답은 독립 정답과 구분해요.

백업과 삭제

백업 파일은 내보내기 버튼을 눌렀을 때만 생성돼요. 파일에는 별명과 학습 기록이 들어 있으니 안전한 곳에 보관해 주세요. 현재 기록 삭제는 현재 게스트 또는 Google 사용자의 이 기기 기록만 지워요. 로그아웃은 계정 표시를 없애고 게스트 기록으로 돌아가며 기존 기록은 삭제하지 않아요.
